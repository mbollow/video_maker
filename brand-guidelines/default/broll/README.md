# B-Roll für diese Marke

Lege hier deine **eigenen Clips** ab (`.mp4`) — Cutaways, die in deinen Reels
etwa alle 10 Sekunden eingeblendet werden (je 2,5–3,5 s, jeder Clip nur 1× pro
Reel).

Nach dem Ablegen sag Claude: **„Bau den B-Roll-Katalog für default"** — dann
werden Frames extrahiert, der Inhalt per Vision beschrieben und hier eine
`catalog.json` erzeugt. Die Composition-Stage wählt daraus per Stichwort-Match
gegen das Gesprochene — **nicht** über Dateinamen (die müssen nicht sprechend
sein).

Solange dieser Ordner leer ist, fällt die Marke auf reinen Talking-Head zurück
(kein Cutaway). Quelle = deine eigene Bibliothek, kein Auto-Stock.
