# Brand-Assets

Hier kommen Logo und Bilder deiner Marke rein. Pfadkonvention:

- `logo-horizontal.png` (oder `.svg`) — Logo für Overlays/Lower-Thirds
- `logo-mark.png` — quadratisches Logo/Icon
- weitere Bilder nach Bedarf

`logo-weiss.png` ist aus `logo-color.png` abgeleitet: dieselbe Wortmarke **inklusive
Claim**, das dunkle Blau in Weiß, der Claim bleibt Teal. Gebraucht, wo das Logo über
Bildmaterial liegt (Testimonial-Antworten) und das dunkle untergeht. Die offizielle
weiße Fassung `logo-horizontal.png` passt dort nicht: sie kommt ohne Claim, die
Wortmarke fällt in derselben Box dadurch größer aus und springt sichtbar, sobald das
Video auf eine Folie schneidet.

Solange hier nichts liegt, rendern die Compositions ohne Logo-Overlay — das ist
okay. Du kannst Logo/Bilder jederzeit nachlegen; im Design-Interview legt ihr
fest, wo das Logo im Reel auftaucht.
